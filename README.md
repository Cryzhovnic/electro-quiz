# Electro Quiz

Тренажёр по электробезопасности: https://cryzhovnic.github.io/electro-quiz/

## Вопросы

Все вопросы лежат в одном файле — `data/exam_data.txt`. Тот же формат и тот же файл
использует Telegram-бот elecbot: правишь вопросы один раз и кладёшь файл в оба проекта.

Формат (подробнее в шапке самого файла):

```
# Билет 1

? Текст вопроса
- неверный вариант
+ правильный вариант
- неверный вариант

? Следующий вопрос, который
можно писать на нескольких строках
+ правильный
- неверный
```

- `# Билет N` начинает билет, номера идут подряд с 1.
- `? ` начинает вопрос, `- ` неверный вариант, `+ ` правильный (ровно один).
- Строка без маркера продолжает предыдущую, и перенос строки показывается как есть.
  Продолжение не должно начинаться с `? `, `+ ` или `- `.
- Пустые строки ни на что не влияют. Строки `//` — комментарии.

Сайт разбирает файл в `js/app.js` (`parseExamData`), бот — в `data.go`. Правила одинаковые.
После изменения формата или данных обнови версию кэша `CACHE` в `sw.js`, чтобы офлайн-копия обновилась сразу.
